# Инвентарь синхронизации сетевого заезда

Документ отвечает на вопрос «что именно должно совпадать у хоста и клиента,
и что из этого уже сделано». Составлен по коду; обновлять вместе с протоколом.

Обозначения в таблицах:
- **OK** — у клиента есть то же, что у хоста (своими средствами или по сети).
- **~** — синхронизировано частично (видно, но чего-то не хватает).
- **нет** — у клиента этого нет.

## 1. Модель

- Хост — единственная авторитетная симуляция. Клиент **свой** болид считает
  локально (отклик на клавиши) и раз в секунду сверяет с хостом; **чужие**
  болиды ведёт по снапшотам с интерполяцией.
- Классы сущностей:
  - **A — гонщики.** Снапшоты (поза/скорость/поворот) + интерполяция,
    редкая жёсткая коррекция локального болида (`net_reconcile_local`).
  - **B — баллистика/фабричные тела.** Спавн с начальными условиями, дальше
    общая физика; клиентский визуал едет вместе со спавном (`netSpawn::client_link`).
  - **C — ходячие/самонаводящиеся.** Хост владеет позой и шлёт батчи состояния
    на 10 Гц; клиент **не** создаёт мировых акторов сам, ждёт спавн.
  - **D — косметика.** Общий сид `fxlabClientRND`, одни и те же эффекты
    воспроизводятся из одного потока, по сети не идут.

## 2. Каталог сообщений (`net_protocol.h`)

Транспорт/лобби: `PING`, `PONG`, `HELLO`, `WELCOME`, `ROSTER`, `READY`,
`START_GAME`, `LEAVE`, `KICK`.
Игра: `INPUT`, `SNAPSHOT`, `EVENT`, `SPAWN`, `DESPAWN`, `ACTOR_STATE`,
`GAME_OVER`.

## 3. Каталог событий (`netEventTypes`)

Используются:
- `NET_EV_ARCANE_CAST` — клиент просит хост скастовать; хост рассылает визуал.
- `NET_EV_ARCANE_INTERRUPT` — хост шлёт точку визуального прерывания.
- `NET_EV_ARCANE_STOP` — клиент просит хост остановить аркан.
- `NET_EV_ARCANE_STOP_VISUAL` — хост снимает клиентский визуал аркана.
- `NET_EV_ARCANE_LATCH` — аркан «прицепился» к жертве (VoodooMaster, 39).

**Объявлено, но не используется:** `NET_EV_RACER_DESTROYED`,
`NET_EV_RACER_RESPAWN`, `NET_EV_RACER_FINISHED`, `NET_EV_HORN`,
`NET_EV_SLOT_TAKEN`, `NET_EV_CHAT`.

Поля `netEvent`: `type`, `slot`, `pos_{x,y,z}`, `part`, `arcane_id`,
`target_id`, `reserved`, `time_ms`. Заняты все, кроме `time_ms`.

## 4. Что уже синхронизировано (общее)

| Действие/событие | Механизм |
|---|---|
| Поза, поворот, скорость гонщиков | `SNAPSHOT`, интерполяция (A) |
| Разрушение/сборка мехоса | `mech_state` в снапшоте |
| Мана и `Status` арканов по частям | `part_power[]`/`part_status[]` |
| Место/круг/чекпоинт гонщиков | `place/lap/checkpoint` в снапшоте |
| Время, звёзды, флаг «финиш» гонщика | `time_ms/nstar/flags` в снапшоте |
| Ввод клиента (тяга/руль/кнопки) | `INPUT`, батчи, `set_net_input` |
| Каст аркана клиента на хосте | `EV_ARCANE_CAST` |
| Визуал каста аркана (в т.ч. свой) | `EV_ARCANE_CAST` |
| Визуал прерывания (шторм/семя) | `EV_ARCANE_INTERRUPT` + позиция |
| Снятие визуала аркана | `EV_ARCANE_STOP_VISUAL` |
| Снаряды класса B | `SPAWN` (по типам + фабричные имена) |
| Мировые акторы класса C | `SPAWN` + `ACTOR_STATE` 10 Гц |
| Повторный спавн акторов вошедшему | `net_fx_resend_actors` |
| Старт заезда по тику | `START_GAME` + `ms_until_start` |
| AI по ростеру (слот занят/пуст) | `net_update_ai` |
| Косметический RNG | сид в `WELCOME` |
| Конец заезда | `NET_MSG_GAME_OVER` (хост → клиенты) |
| Сигнал (HORN) чужого гонщика | `NET_EV_HORN` (хост релеит) |
| Запрет паузы/Pause в заезде | `mchNetQuant` + гард VK_PAUSE |
| Запрет выхода в меню по Escape | гард `MCH_KEY_EXIT` |

## 6. Что ещё НЕ синхронизировано

1. **Финиш отдельного гонщика.** `NET_EV_RACER_FINISHED` не используется;
   финиш удалённой машины виден по её `lap/place/flags` из снапшота, но без
   отдельного события.
2. **Оставшиеся поля `netRacerState`, которые есть, но не заполняются:**
   `features[3]`, `part_kind[]`/`part_arcane[]`, `bonus_count` + `netBonus[]`,
   `kind`. Для HUD/визуала удалённых машин пока не нужны: визуальные фичи
   приезжают событиями арканов.
3. **Подобранные бонусы/семена (`seeds`).** Не шлются; удалённые машины
   рисуются без своих семян/очков.
4. **Звук/вспышка каста и подбора у чужого гонщика.** Тела и модели синхронны,
   но некоторые звуки (напр. у 007 EvilEye) проигрываются только на хосте.
5. **Чат.** `NET_EV_CHAT` объявлен, не реализован.
6. **Кнопки-команды (`NET_BTN_ARCANE_REMOVE`, `NET_BTN_MAP`,
   `NET_BTN_CENTER_VIEW`).** Хост через `set_net_input` их не разбирает.
7. **Урон удалённых машин.** Клиент урон не наносит и не получает; виден
   только итоговый `mech_state` (взрыв/сборка), без промежуточного здоровья.
   Энергия (`energy`) уже шлётся, но HUD её для чужих машин пока не рисует.
8. **Точки управления / семена AI.** Хост-локально; клиент их не знает.
9. **Погода/время суток.** Не синхронизируются (пока константа мира).

## 7. Известные проблемы вне синхронизации

- **Крэш при F2/F3 в меню мультиплеера** — воспроизводится, отложено
  (пользователь просил пока не чинить). Ярлык: жёстко зашитый путь
  `ACS_EXT.CPP` → `MainMenuRTO`.

## 8. Приоритеты (предложение)

1. Финиш отдельного гонщика событием + полноценные результаты/очки.
2. Бонусы/семена удалённых машин.
3. Чат и кнопки-команды.
4. Оставшиеся звуки у чужих кастов.
5. Оставшиеся поля снапшота (`features`/`part_kind`/`part_arcane`/`kind`) —
   если понадобятся для HUD.
6. F2/F3-крэш меню.
