# Инвентарь синхронизации сетевого заезда

Документ отвечает на вопрос «что именно должно совпадать у хоста и клиента,
и что из этого уже сделано». Составлен по коду на момент коммита с фиксом
Escape/таблицы заезда. Обновлять вместе с протоколом.

## 1. Модель

- Хост — единственная авторитетная симуляция. Клиент **свой** болид считает
  локально (отклик на клавиши) и раз в секунду сверяет с хостом; **чужие**
  болиды ведёт по снапшотам с интерполяцией.
- Классы сущностей:
  - **A — гонщики.** Снапшоты (поза/скорость/поворот) + интерполяция,
    редкая жёсткая коррекция локального болида (`net_reconcile_local`).
  - **B — баллистика/фабричные тела.** Спавн с начальными условиями, дальше
    общая физика; клиентский визуал едет вместе со спавном (`netSpawn::client_link`).
  - **C — ходячие/самонаводящиеся.** Хост владеет позой и шлёт батчи состояния
    на 10 Гц; клиент **не** создаёт мировых акторов сам, ждёт спавн.
  - **D — косметика.** Общий сид `fxlabClientRND`, одни и те же эффекты
    воспроизводятся из одного потока, по сети не идут.

## 2. Каталог сообщений (`net_protocol.h`)

Транспорт/лобби: `PING`, `PONG`, `HELLO`, `WELCOME`, `ROSTER`, `READY`,
`START_GAME`, `LEAVE`, `KICK`.
Игра: `INPUT`, `SNAPSHOT`, `EVENT`, `SPAWN`, `DESPAWN`, `ACTOR_STATE`.

**Объявлено, но не используется:** `NET_MSG_GAME_OVER`.

## 3. Каталог событий (`netEventTypes`)

Используются:
- `NET_EV_ARCANE_CAST` — клиент просит хост скастовать; хост рассылает визуал.
- `NET_EV_ARCANE_INTERRUPT` — хост шлёт точку визуального прерывания.
- `NET_EV_ARCANE_STOP` — клиент просит хост остановить аркан.
- `NET_EV_ARCANE_STOP_VISUAL` — хост снимает клиентский визуал аркана.

**Объявлено, но не используется:** `NET_EV_RACER_DESTROYED`,
`NET_EV_RACER_RESPAWN`, `NET_EV_RACER_FINISHED`, `NET_EV_HORN`,
`NET_EV_SLOT_TAKEN`, `NET_EV_CHAT`.

Поля `netEvent`: `type`, `slot`, `pos_{x,y,z}`, `part`, `arcane_id`,
`target_id`, `reserved`, `time_ms` — `target_id`/`time_ms` пока не задействованы.

## 4. Что уже синхронизировано

| Действие/событие | Механизм |
|---|---|
| Поза, поворот, скорость гонщиков | `SNAPSHOT`, интерполяция (A) |
| Разрушение/сборка мехоса | `mech_state` в снапшоте + `net_apply_state` |
| Мана и `Status` арканов по частям | `part_power[]`/`part_status[]` |
| Ввод клиента (тяга/руль/кнопки) | `INPUT`, батчи, `set_net_input` |
| Каст аркана клиента на хосте | `EV_ARCANE_CAST` |
| Визуал каста аркана (в т.ч. свой) | `EV_ARCANE_CAST` (хост шлёт слот) |
| Визуал прерывания (шторм/семя) | `EV_ARCANE_INTERRUPT` + позиция |
| Снятие визуала аркана | `EV_ARCANE_STOP_VISUAL` |
| Фичи арканов 038/050/051/052/059/060/011/014 | `fxlabClientArcaneStart` |
| Снаряды класса B | `SPAWN` (по типам + фабричные имена) |
| Клиентский визуал снаряда | `netSpawn::client_link` |
| Мировые акторы класса C (BonusMan 1–4, Butterfly/Wicked, Caterpillar, Worm, Dragon, Frog, Shark, Fish) | `SPAWN` + `ACTOR_STATE` 10 Гц |
| Повторный спавн акторов вошедшему игроку | `net_fx_resend_actors` |
| Старт заезда по тику | `START_GAME` + `ms_until_start` |
| AI по ростеру (слот занят/пуст) | `net_update_ai` |
| Косметический RNG | сид в `WELCOME` |
| Место/круг/чекпоинт гонщиков | `place/lap/checkpoint` в снапшоте (добавлено) |
| Латч головы VoodooMaster (аркан 39) на жертву | `NET_EV_ARCANE_LATCH` (`target_id`) |
| Запрет паузы/Pause в сетевом заезде | `mchNetQuant` + гард VK_PAUSE |
| Запрет выхода в меню по Escape | гард `MCH_KEY_EXIT` (добавлено) |

## 5. Что НЕ синхронизировано (пробелы)

1. **Масс-шифтер «0-Телепорт» (аркан 58).** Визуал ставится и в старте, и в
   точке назначения; точка назначения считается на хосте из чекпоинтов и по
   событию не приходит. Нужна позиция назначения в событии аркана.
2. **Петарда (аркан 2), момент взрыва.** `ExplodePosition` считается на хосте;
   событие-прерывание не отличает бросок (`InterruptCount==0`) от взрыва.
   Бонусные коробки после взрыва уже реплицируются как класс B, не хватает
   только вспышки в правильной точке.
3. **Конец заезда.** `NET_MSG_GAME_OVER` объявлен, но не отправляется и не
   обрабатывается. Клиент не узнаёт с хоста, что заезд окончен/финишировал
   и кто первый.
4. **Финиш отдельного гонщика.** `NET_EV_RACER_FINISHED` не используется;
   финиш удалённой машины локально не виден.
5. **Поля `netRacerState`, которые есть, но не заполняются:**
   `energy` (энергия/здоровье), `flags`, `features[3]` (визуальные фичи
   удалённой машины), `part_kind[]`/`part_arcane[]`, `bonus_count` +
   `netBonus[]` (подобранные бонусы), `time_ms` (время круга/заезда),
   `kind`. Часть нужна для полноты HUD/визуала удалённых машин.
6. **Время заезда/круга (`time_ms`).** Каждая машина считает по своему
   `clocki()`; часы удалённых гонщиков в таблице разойдутся.
7. **Звёзды `NStar`.** Не шлются — очки удалённых машин в HUD не видны.
8. **Подобранные бонусы/семена (`seeds`).** Не шлются; удалённые машины
   рисуются без своих семян/очков за бонусы.
9. **Сигнал (HORN).** `NET_EV_HORN` и `NET_BTN_HORN` объявлены, не
   обрабатываются.
10. **Чат.** `NET_EV_CHAT` объявлен, не реализован.
11. **Кнопки-команды (`NET_BTN_ARCANE_REMOVE`, `NET_BTN_MAP`,
    `NET_BTN_CENTER_VIEW`).** Хост через `set_net_input` их не разбирает.
12. **Урон удалённых машин.** Клиент урон не наносит и не получает; виден
    только итоговый `mech_state` (взрыв/сборка), без промежуточного здоровья.
13. **Точки управления / семена AI.** Хост-локально; клиент их не знает
    (для позы это неважно, для HUD — да).
14. **Погода/время суток.** Не синхронизируются (пока константа мира).

## 6. Известные проблемы вне синхронизации

- **Крэш при F2/F3 в меню мультиплеера** — воспроизводится, отложено
  (пользователь просил пока не чинить). Ярлык: жёстко зашитый путь
  `ACS_EXT.CPP` → `MainMenuRTO`.

## 7. Приоритеты (предложение)

1. Конец заезда (`GAME_OVER`) + финиш гонщика — без этого нельзя играть
   матч до конца.
2. Время/звёзды/бонусы в снапшот — полнота HUD.
3. Петарда-взрыв и Масс-шифтер — по событию аркана.
4. Сигнал/чат/команды кнопок — мелочи.
5. F2/F3-крэш меню.
